# WeChat Parent Feedback Rules

## Purpose
Generate a concise, warm, evidence-linked parent feedback draft for teacher review.

## Required Qualities
- Suitable for WeChat.
- Short and natural.
- Evidence-based.
- Focused on current learning state and next step.
- No Markdown titles or formal report style.

## Review Gate
- Before teacher confirmation, status must be draft, blocked, or needs_teacher_review.
- ready_to_send is forbidden before teacher confirmation.
- Each sentence should have evidenceRefs or be a safe connective sentence tied to evidenced content.

## Forbidden Expressions
- 严重
- 很差
- 完全不会
- 保证提分
- 不认真
- 基础很差
- 一定能提高
- 一定提升
- 孩子不行
- 家长必须

## Degrade Rules
- If material evidence is weak, generate a teacher-only note or ask for review instead of parent feedback.
- If correctness is unknown, describe observed material state rather than judging mastery.
