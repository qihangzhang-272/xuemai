## 设计理解

学脉是教师教学服务工作台，不是传统校务后台。视觉需要安静、可信、轻量；信息密度可以高，但每个区域只回答一个问题：现在该处理什么、依据是什么、处理后会发生什么。

## 文件

- `tokens/colors_and_type.css`：颜色、字体、圆角、阴影和间距令牌。
- `brand/voice-and-tone.md`：面向老师的文案规则。
- `SKILL.md`：可复用设计约束。
