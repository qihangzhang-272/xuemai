# 学脉 AI 手机 App 开发规划

> 未来原生 App 规划稿：不属于当前 V4.0 范围。当前产品形态与发布门槛见 `docs/PRD.md`。

## 1. 当前结论

手机 App 已从早期“四 Tab 快速反馈工具”升级为 **学脉 AI：AI Agent 教学工作台**。

当前开发以新的《学脉 AI 移动端 App 开发 PRD》为准，第一阶段先完成一个可运行、可点击、可演示的 Expo App 原型。

第一阶段不接真实后端、真实 AI、真实图片上传或真实通知，先用 mock data 跑通页面、路由、状态流转和核心工作流。

## 2. 产品定位

学脉 AI 是给个体老师和小型教培机构使用的移动端 AI Agent 教学工作台。

老师可以通过两种方式使用：

- 在首页底部 AI 输入框用自然语言指挥 AI。
- 手动进入今日、班级、AI 助教、报告、我的等功能页面。

App 的核心目标是帮助老师追踪学生学情、生成家长反馈、处理错题分析、沉淀 AI 记忆，并预览月报。

## 3. 首版范围

第一阶段必须优先跑通：

1. 启动页、登录、注册、忘记密码、身份选择。
2. 今日工作台。
3. 首页底部固定 AI 输入框。
4. 学生建档和学生详情。
5. 班级列表、新建班级、班级详情。
6. 批量反馈。
7. AI 助教。
8. 拍照上传和图片确认模拟流程。
9. AI 分析中和 AI 分析结果。
10. 家长反馈生成、编辑、复制和发送确认。
11. 月报列表和月报详情。
12. 通知中心。
13. 我的页面和设置类底部弹窗。
14. 权限与异常状态的基础承接。

第一阶段暂不做：

- 学生端。
- 家长端。
- 微信小程序。
- 支付系统。
- 复杂机构权限。
- 多员工协作。
- 财务模块。
- 大型 CRM。
- 真实微信自动发送。
- 真实排课系统复杂对接。
- 完整后台管理系统。

系统只负责生成可复制的微信反馈，不自动发送微信消息，也不自动确认已发送。

## 4. 技术方案

使用 Expo React Native + TypeScript 开发跨平台 App。

工程位置：

- `mobile/`

开发目标：

- iOS 和 Android 都保留下载与打包能力。
- 当前优先使用 Expo Go 或开发构建验证。
- 第一阶段图片上传、AI 分析、反馈生成和通知均为 mock。
- 后续再接 Supabase、真实图片存储、真实 AI API 和真实通知。

安全边界：

- 移动端不得保存 AI API Key；DeepSeek/OpenAI-compatible 等模型密钥只能在服务端读取。
- 移动端不得保存 Supabase service role key。
- AI 调用只能通过项目自己的服务端 API route 完成。
- 移动端后续只保存可公开的客户端环境变量，例如 Supabase anon key。

## 5. 导航结构

底部 Tab 固定为五个：

1. 今日。
2. 班级。
3. AI 助教。
4. 报告。
5. 我的。

说明：

- AI 批改统一命名为 AI 助教。
- 首页必须保留底部固定 AI 输入框。
- 月报作为底部一级 Tab，承载月报列表和详情。

## 6. Mock 数据要求

第一阶段至少包含：

- 6 个以上学生。
- 2 个以上班级。
- 4 个以上反馈任务。
- 3 条以上通知。
- 4 条以上 AI 任务。
- 5 条以上 AI 操作记录。
- 2 份以上月报。

mock 数据必须保留真实后端可替换的结构，避免把业务逻辑写死在页面组件中。

## 7. 核心流程

必须跑通以下演示流程：

1. 创建学生并模拟自动生成课后反馈任务。
2. 首页展示待反馈学生，点击立即处理进入反馈流程。
3. 生成家长反馈，编辑后复制到微信。
4. 复制后弹出发送确认。
5. 标记已发送后，反馈任务变为完成，学生状态同步更新。
6. 班级详情进入批量反馈，选择多个学生并批量生成反馈。
7. AI 助教进入拍照批改，模拟上传、分析中、分析结果。
8. 首页 AI 输入框识别“处理今日反馈”等指令并跳转到对应工作流。
9. 月报列表进入详情，支持家长版和老师复盘版切换。

## 8. 发布准备

后续进入真实发布前需要补充：

- App 图标。
- 启动图。
- iOS bundle identifier。
- Android package name。
- 相机、相册、通知权限说明。
- 隐私政策。
- EAS Build 配置。
- Android 真机测试。
- iOS 模拟器或真机测试。
- App Store / 应用市场上架材料。

## 9. 验证要求

Web 根工程继续运行：

```bash
npm run lint
npm run typecheck
npm run build
```

移动端工程运行：

```bash
cd mobile
npm run lint
npm run typecheck
npm run web
npm run android
npm run ios
```

如果某个命令因为本机环境缺少模拟器、真机或权限而不可用，必须在开发日记中说明。
