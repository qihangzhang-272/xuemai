## 隔离方案

新项目只复制复用 MDT 的解析、密码、文本校验等通用代码和已授权的模型配置。MDT 连接用于教师认证、班级及学生学情读取；新增课堂记录、材料、反馈、档案全部进入学脉独立存储。没有修改原项目代码、执行原项目迁移、回写原项目业务数据或重启原项目服务。

源码包通过当前 Git 提交生成，不包含 `.env.local`、`.local-access.txt`、数据库、用户上传、`node_modules`、旧构建或本地调试输出。Git 历史保留变更来源，不改写历史提交。

## 使用边界

当前原版前端接通独立登录、学生班级表单、材料分析、课堂记录、备课、反馈、入档、学生月报、班级导入及导出等核心操作。

原版中的批量处理、班级自动拆分入口尚未接通；目前应逐位进入学生会话处理。排课、课时、反馈提醒等规则只保存资料，没有后台调度。微信不自动发送。侧边追问仅在当前页面保留；未提交输入和编辑草稿不保证刷新保留。未提供按钮操作历史；确认版本、发送正文和入档快照保存在后端。

本轮没有公网部署、真实教师课堂 UAT、实体手机验证、负载测试或完整 PRD 的机构协作、小程序、收费排课、AI 出题批改。
