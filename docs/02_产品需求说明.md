# 产品需求说明

> 历史需求快照：当前完整产品需求统一见 `docs/PRD.md`。本文中的多 Agent、旧页面和阶段范围仅作为历史参考。

## 一句话定位

学脉 AI 是一个面向老师和教培机构的教学 Agent 工作台，帮助老师把课后反馈、错题分析、学生档案追踪和月度报告生成等教学后续任务交给 AI Agent 执行。

产品核心不是一次性生成内容，而是让老师派发任务，AI 读取学生和班级上下文，透明执行，中途让老师确认，生成可用结果，并把结果沉淀成学生长期档案。练习材料不限定为试卷，也可以是老师手改练习、课堂练习、英语作文、阅读题、口算题或其他作业。

## 目标用户

- 个体教培老师。
- 小型教培机构老师。
- 一对一和小班课老师。
- 经常需要处理练习、作文、测验、作业和阶段考试反馈的老师。
- 经常通过微信向家长反馈考试情况的老师。
- 需要用月度总结辅助续费和服务展示的老师。

## MVP 核心闭环

Agent 工作流主链路固定为：

```text
派任务 -> 执行任务 -> 审核结果 -> 保存档案 -> 下次继续调用
```

第一阶段先用 mock 数据表达这个闭环，后续再接 Supabase 和真实任务数据。

1. 老师注册或登录。
2. 创建班级。
3. 创建学生档案。
4. 老师在 Agent 工作台派发任务。
5. AI 读取学生档案、班级上下文和历史记录。
6. AI 展示执行步骤，并在缺少关键信息时请老师确认。
7. AI 生成微信反馈、错题分析、月报等任务结果。
8. 老师审核、编辑、复制或保存。
9. 系统保存本次学习记录、AI 产物和月度总结素材。
10. 下一次任务继续调用学生长期档案。

## 六个核心 Agent

- 反馈 Agent：根据课堂表现、作业和错题生成家长微信反馈。
- 错题 Agent：整理知识点、错误原因和训练建议。
- 月报 Agent：汇总一个月记录，生成学生学习报告。
- 档案 Agent：把课堂记录、反馈和错题整理进学生长期档案。
- 话术 Agent：把老师专业判断转成家长能接受的微信话术。
- 班级 Agent：批量处理班级反馈、月报和重点学生跟进。

## 第一阶段页面需求

- `/`：简单首页，说明“给教培老师的 AI 练习反馈工作台”。
- `/login`：登录表单 UI，第一阶段临时免登录。
- `/dashboard`：Agent 工作台，老师自然语言派任务，查看快捷 Agent、执行中任务、最近产物和当前上下文。
- `/classes`：班级列表 mock 页面。
- `/classes/new`：新建班级表单 UI。
- `/students`：学生列表、搜索框、新建学生入口。
- `/students/new`：新建学生表单 UI。
- `/students/[id]`：学生详情、微信反馈记录、练习记录、错题记录和月度总结入口。
- `/students/[id]/feedback/new`：左侧练习材料表单，右侧只展示微信反馈预览。
- `/settings`：账号设置和 AI 输出偏好占位。

## 明确不做

- 不做学生端。
- 不做家长端。
- 不做微信小程序。
- 不做支付系统。
- 不做复杂排课。
- 不做完整 LMS 或 ERP。
- 不做 OCR 自动批改。
- 不做完整题库。
- 不做复杂多角色权限。
