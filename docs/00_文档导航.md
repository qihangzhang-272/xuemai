# 项目文档导航

这个目录存放项目开发相关的长期标准文件。后续需求、技术、设计和执行步骤都应该优先沉淀到这里。

## 文档入口

- `docs/PRD.md`：当前唯一完整产品需求基线；历史范围、页面和竞品文档与其冲突时，以根目录 `AGENTS.md` 和本文件为准。
- `docs/产品功能结构.md`：个人版与机构版的完整产品功能总地图，覆盖页面、模块、状态、版本优先级和明确不做范围。
- `docs/产品本体与产品形态.md`：从学生、关系、事件、证据、结论产物和责任承诺出发重组功能，定义一个核心、两种模式和五个主页面的上位产品形态。
- `docs/PRD_理想版.md`：学脉 24 个月理想终局 Vision PRD，用于北极星、架构预留和产品叙事，不直接扩大当前开发范围。
- `docs/00_文档导航.md`：文档导航，说明各标准文件路径和用途。
- `docs/01_产品范围说明.md`：产品范围，说明 MVP 做什么、不做什么。
- `docs/02_产品需求说明.md`：产品需求，说明用户、核心闭环、页面和阶段目标。
- `docs/03_技术规范.md`：技术规范，说明技术栈、目录约定、安全规则和后续接口原则。
- `docs/04_设计规范.md`：设计规范，说明视觉风格、布局、颜色、组件使用原则。
- `docs/05_阶段开发计划.md`：阶段计划，说明 Phase 0 到 Phase 8 的推进顺序。
- `docs/06_开发流程规范.md`：开发流程，说明每次开发前后如何说明、验收和更新开发日记。
- `docs/07_电脑端Web界面PRD.md`：电脑端 Web 设计用 PRD，说明工作台、班级模式、学生档案和微信反馈生成。
- `docs/08_手机App界面PRD.md`：手机 App 设计用 PRD，说明移动端快速拍照/录入、生成反馈和复制微信流程。
- `docs/09_手机App开发规划.md`：手机 App 后续开发规划，说明范围、技术方案、后端衔接、MVP 顺序和发布准备。
- `docs/10_Codex开发总任务书.md`：Codex Web 端开发总任务书，沉淀 Agent 工作台开发优先级、阶段边界和验收重点。
- `docs/codex/学脉_Teaching_Agent_OS_Codex_开发指导书_v1.2_审校修正版.md`：Teaching Agent OS 长期架构指导书。
- `docs/codex/task-plan.md`：Codex 当前 Phase、任务状态和下一步计划。
- `docs/codex/dev-log.md`：Phase 级别阶段总结，不记录流水账。
- `docs/codex/decision-log.md`：长期架构、数据库、Agent Harness、权限安全和数据生命周期关键决策。
- `docs/harness/README.md`：Agent Harness Core 分层说明。
- `docs/product/README.md`：Teaching Agent OS 产品长期闭环说明。
- `docs/stitch/AI练习反馈_手机App_Stitch_PRD.md`：Stitch 专用手机 App PRD，可直接作为生成移动端 UI 的提示词和需求说明。

## Codex 接续入口

- 后续 Codex 应优先读取 `AGENTS.md`、`docs/PRD.md`、`docs/codex/task-plan.md`、`docs/codex/dev-log.md` 和 `docs/codex/decision-log.md`。
- `开发日记/` 保留历史记录，不再作为默认新增入口。

## 使用规则

- 聊天中的临时想法，如果会影响长期开发，应整理进对应文档。
- 不记录低价值流水账；只有阶段总结和关键决策进入 `docs/codex/`。
- 每次进入新阶段前，先阅读 `docs/PRD.md`、`docs/05_阶段开发计划.md` 和 `docs/06_开发流程规范.md`。
- 每次改 UI 前，先阅读 `docs/04_设计规范.md`。
- 每次推进手机 App 前，先阅读 `docs/08_手机App界面PRD.md` 和 `docs/09_手机App开发规划.md`。
- 每次接数据库、认证或 AI 前，先阅读 `docs/03_技术规范.md`。
