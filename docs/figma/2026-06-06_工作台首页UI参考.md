## 页面定位

这是学脉 AI 的“今日主页 / 工作台首页”，用于老师进入系统后的日常任务处理入口。

它不是传统后台 Dashboard，而是老师的当日教学 Agent 工作台，重点呈现：

- 今日待处理任务；
- 我的学生；
- 推荐任务；
- 班级报告入口；
- 最近动态；
- 自然语言任务输入框；
- 右侧今日提醒、重点学生、待确认和 Agent 记忆偏好。

## 结构记录

### 左侧导航

- 学脉 AI 标识；
- 首页；
- 学生档案；
- 班级空间；
- AI 反馈；
- 月度报告；
- 素材库；
- 设置。

设计要求：

- 左侧栏固定；
- 当前页面“首页”用绿色高亮；
- 图标使用项目现有 `lucide-react` 替代外部 Material Symbols；
- 保持中文界面。

### 中央主工作区

核心模块：

- 顶部问候：`早上好，Eric 老师`；
- 今日任务数量提示；
- 搜索学生或班级；
- 我的学生头像入口；
- 推荐任务 2x2 卡片；
- 班级报告横向提示卡；
- 最近动态时间轴；
- 底部任务输入框。

推荐任务示例：

- 需要复习；
- 李明轩几何报错；
- 4 份月报待生成；
- 3 名学生需关注。

注意：

- 以上文案是视觉模板，真实页面实现时应从 mock 数据或后续 AI 生成层推导；
- 不要把截图里的具体学生标签全部写死在组件里。

### 右侧上下文栏

核心模块：

- 日期；
- 今日提醒；
- 重点学生；
- 待确认；
- Agent 记忆偏好。

设计要求：

- 右侧栏作为上下文 inspector；
- 不做重型数据后台；
- 留白适中，但整体比旧首页更紧凑；
- 与学生详情页、班级详情页的 Warm Humanist 视觉保持一致。

## 实现提醒

后续重做 `/dashboard` 时，应优先处理：

1. 保持三栏桌面布局：左导航 / 中央今日工作台 / 右上下文栏。
2. 首页需要能进入新版学生详情页 `/students/mock-student-1`。
3. 首页需要能进入新版班级详情页 `/classes/mock-class-1`。
4. 推荐任务卡片按钮先做 mock toast 或跳转。
5. 底部输入框先做前端 mock，不接真实 AI。
6. 具体提醒、重点学生、任务卡片内容应来自 mock 数据生成，而不是写死视觉模板。
