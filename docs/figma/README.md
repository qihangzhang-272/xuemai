## 导入方式

1. 打开 Figma 文件 `AI 练习反馈 MVP V2`。
2. 将 `AI练习反馈MVP_V2_导入稿.svg` 直接拖入 Figma 画布。
3. 导入后可按画板标题拆分、复制、微调。

## 设计原则

- 左侧栏支持展开和折叠。
- 学生圆点控制在 44-52px，圆点里只放简称。
- 完整姓名、核心问题、状态放在选中学生详情区。
- 班级选择只出现在班级页。
- 返回按钮只出现在二级页面。
- 避免飞书式后台和维基百科式裸文本。
