# Codex 开发总任务书

> 历史开发任务书：后续开发先以 `AGENTS.md`、`docs/PRD.md` 和 `docs/codex/task-plan.md` 为准。

## 核心定位

学脉 AI 是面向老师和教培机构的桌面端 Web AI Agent 工作台。

核心心智：

```text
老师不是来点功能的，老师是来派任务的。
```

核心链路：

```text
老师派任务 -> AI Agent 执行任务 -> 展示执行过程 -> 老师补充确认信息 -> 审核生成结果 -> 保存到学生档案 -> 下次继续基于学生档案生成
```

## 当前阶段边界

- 先开发 Web 端 MVP Demo。
- 先使用 Mock 数据。
- 不接真实 AI。
- 不接 Supabase。
- 不做数据库持久化。
- 所有用户可见界面文字必须使用中文。
- 页面必须是桌面端 Web 应用，不做手机 App，不使用底部 Tab。
- 风格保持 Apple 式克制界面：浅灰背景、白色卡片、大圆角、轻阴影、绿色主色。

## 第一阶段必须完成

1. 全局布局。
2. 左侧导航。
3. `/dashboard` 首页。
4. `/tasks/[id]` 任务执行详情页。
5. `/dashboard` 到 `/tasks/demo-feedback-task` 的跳转。
6. 任务执行详情页中的确认、编辑、复制、保存 Mock 交互。
7. Mock 数据集中管理。
8. 所有界面中文。

## 后续阶段

- 第二阶段：学生列表、学生档案详情、学生卡片跳转、学生详情快捷 Agent 跳转任务页。
- 第三阶段：班级列表、班级详情、批量反馈页、设置中心。
- 第四阶段：月度报告、错题详情、素材库、真实 AI、Supabase、用户登录、文件上传、PDF 导出。

## 验收重点

- `/dashboard` 可以访问。
- `/tasks/demo-feedback-task` 可以访问。
- 左侧导航正常显示并可跳转。
- 首页有大型 Agent 输入框、6 个快捷 Agent、正在执行任务和右侧上下文。
- 任务详情页有任务目标、执行步骤、执行日志、老师确认卡片和生成结果预览。
- 确认、编辑、复制、保存等交互在前端可用。
- 页面没有英文导航和英文按钮。
- 页面是桌面端布局，不出现底部 Tab 或手机化单列布局。
