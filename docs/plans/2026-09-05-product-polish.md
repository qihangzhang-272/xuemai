# 老师日常操作细节检查与修复

约束：沿用提供的学脉前端组件、配色与布局，只修数据适配、内容展示和操作缺口；不修改多维度教学助手项目。

1. 按老师的真实路径复现：选择学生或班级、提交材料、读结果、编辑、反馈、入档、生成报告、查看设置。截图与实际代码共同确认问题。
2. 修复共同原因：统一正文排版；去掉重复的来源文案；报告先选对象和时间；快捷操作不覆盖输入；保存失败保留编辑；去掉未实现功能的虚假状态和入口。
3. 验证：为正文渲染、报告范围和数据适配留下回归检查，执行类型、代码规范、测试和生产构建，再在浏览器检查桌面及手机操作。
4. 输出带证据的检查报告：区分本次修复、已验证范围与尚未支持的能力，不将测试数量当作完整产品验收。
